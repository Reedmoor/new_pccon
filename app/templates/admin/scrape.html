DNS Parser

Парсинг выполняется локально через главное меню.

Инструкция (DNS):

Запустите на своём ПК:

local_parser/main_menu.bat (можно ярлык с рабочего стола)

В меню выберите пункт:

1 — парсинг DNS + автозагрузка на сервер основной

Пункты 2–14 — дополнительные и отладочные (импорт, синхронизация, тесты Docker и т.д.). Для обычной работы они не нужны.

Как это работает:

  1. Открываете main_menu.bat → вводите 1
  2. Выбираете категорию DNS и количество товаров
  3. Парсер собирает данные и отправляет их на этот сервер
  4. Товары появляются в базе данных сайта

Citilink Parser

Парсинг выполняется локально через главное меню.

Инструкция (Citilink):

Запустите на своём ПК:

local_parser/main_menu.bat (можно ярлык с рабочего стола)

В меню выберите пункт:

15 — парсинг Citilink (категория + автозагрузка) основной

Пункт 16 — только загрузка уже собранного дампа. Пункты 1–14 — DNS и отладочные операции.

Как это работает:

  1. Открываете main_menu.bat → вводите 15
  2. Выбираете категорию Citilink (видеокарты, процессоры и т.д.)
  3. Парсер (app/utils/Citi_parser/) сохраняет дамп в data/citilink/citilink_*.json
  4. Данные автоматически отправляются на сервер и импортируются в БД

API: /api/upload-products
