# Веб-интерфейс локального DNS парсера

## Обзор

Теперь вы можете запускать локальный DNS парсер прямо из веб-интерфейса администратора! Больше не нужно использовать командную строку или batch файлы.

## Доступ к интерфейсу

1. **Запустите сервер:**
   ```bash
   python run.py
   ```

2. **Откройте браузер и перейдите:**
   ```
   http://localhost:5001/admin/local-parser
   ```

3. **Войдите как администратор:**
   - Email: `admin@pccon.com`
   - Пароль: `admin`

## Функции веб-интерфейса

### 🧪 Test Parser
- **Кнопка**: "Test Parser"
- **Назначение**: Проверяет работоспособность локального парсера
- **Результат**: Показывает статус соединения и готовность парсера

### ⚙️ Start Parsing
- **Кнопка**: "Start Parsing"
- **Назначение**: Открывает модальное окно с опциями парсинга

#### Режимы парсинга:

1. **Single Product (Один товар)**
   - Введите URL товара с DNS-shop
   - Пример: `https://www.dns-shop.ru/product/4a8b7c2d3e4f5g6h/`
   - Нажмите "Parse"

2. **Category Parsing (Парсинг категории)**
   - Выберите категорию из списка:
     - Видеокарты
     - Процессоры  
     - Материнские платы
     - Оперативная память
     - SSD накопители
     - Блоки питания
     - Корпуса
     - Кулеры для процессора
   - Укажите количество товаров (1-50)
   - Нажмите "Start Category Parsing"

## Мониторинг выполнения

### Parser Output
- **Раздел**: Автоматически появляется при запуске парсера
- **Содержит**: 
  - Команду запуска
  - PID процесса
  - Статус выполнения
  - Ошибки (если есть)

### Recent Uploads
- **Обновление**: Автоматически каждые 30 секунд
- **Показывает**:
  - Имя файла с данными
  - Время загрузки
  - Количество товаров
  - Размер файла
  - Статус

### Statistics
- **Total Uploads**: Общее количество загрузок
- **Total Products**: Общее количество товаров
- **Last Upload**: Время последней загрузки
- **Status**: Текущий статус системы

## API Endpoints

Веб-интерфейс использует следующие API endpoints:

### GET `/api/test-connection`
Проверка соединения с сервером

### GET `/api/parser-status`
Получение статуса парсера и списка загрузок

### POST `/api/run-parser`
Запуск локального парсера с параметрами:

```json
{
  "mode": "test|single_product|category",
  "product_url": "https://...",  // для single_product
  "category": "videokarty",      // для category
  "limit": 5                     // для category
}
```

## Устранение проблем

### Парсер не запускается
1. Проверьте, что сервер запущен на порту 5001
2. Убедитесь, что файл `local_parser/local_dns_parser.py` существует
3. Проверьте права доступа к файлам

### Ошибки в Parser Output
1. Скопируйте ошибку из терминала
2. Проверьте зависимости: `pip install -r local_parser/requirements.txt`
3. Убедитесь, что Chrome установлен

### Не отображаются результаты
1. Нажмите кнопку "Refresh" в разделе Recent Uploads
2. Проверьте директорию `data/` на наличие файлов
3. Обновите страницу в браузере

## Следующие шаги

После успешного парсинга:

1. **Просмотр товаров**: Перейдите в "Товары" → просмотрите импортированные товары
2. **Мониторинг**: Оставьте страницу открытой для мониторинга новых загрузок
3. **Автоматизация**: Настройте периодический запуск через cron или планировщик задач

---

**Примечание**: Веб-интерфейс запускает парсер в фоновом режиме. Процесс будет работать даже если вы закроете браузер. Результаты автоматически сохраняются в базу данных.
